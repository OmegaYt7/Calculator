# Калькулятор линейной и векторной алгебры

Веб-калькулятор для решения типовых задач по курсу линейной и векторной алгебры.

## Возможности

### Матрицы
- Сложение и вычитание
- Умножение на число
- Умножение матриц
- Транспонирование
- Определитель (разложение по строке)
- Ранг (метод Гаусса)
- Обратная матрица (метод Гаусса-Жордана)

### Векторы (2D / 3D)
- Сложение и вычитание
- Умножение на число
- Скалярное произведение
- Векторное произведение
- Смешанное произведение
- Длина вектора

### Системы линейных уравнений
- Метод Гаусса (с подробными шагами)
- Метод Крамера
- Матричный метод (через обратную матрицу)

## Как запустить локально

1. Скачай или клонируй репозиторий
2. Открой файл `index.html` в любом современном браузере

Никаких серверов и зависимостей не нужно — всё работает на чистом HTML + CSS + JavaScript.

## Как выложить на GitHub Pages (бесплатный сайт)

1. Создай новый репозиторий на GitHub
2. Залей все файлы в корень репозитория
3. Зайди в Settings → Pages
4. Source: Deploy from a branch → Branch: `main` → Folder: `/ (root)`
5. Через 1–2 минуты сайт будет доступен по адресу:
   `https://твой-логин.github.io/название-репозитория/`

## Структура проекта

```
linear-vector-calculator/
├── index.html              # Главная страница и разметка
├── css/
│   └── style.css           # Стили интерфейса
├── js/
│   ├── main.js             # Переключение вкладок, создание полей, события
│   ├── matrix.js           # Обработчики матричных операций
│   ├── vector.js           # Обработчики векторных операций
│   ├── slaе.js             # Решение СЛАУ тремя методами
│   ├── math-helpers.js     # Математические алгоритмы (det, rank, inverse...)
│   └── utils.js            # Ввод/вывод, ошибки, красивый вывод матриц
└── README.md
```

## Требования задания

- Пользователь сам выбирает размерность
- Ввод с клавиатуры и мышью
- Показываются промежуточные действия
- Сообщения о невозможности операции и о сбоях
- Вычисления выполняются быстро (< 10 сек)
